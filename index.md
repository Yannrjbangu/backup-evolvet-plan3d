# Backup Evolvet Plan3D

Aplicativo de uso privado destinado à realização de backups de segurança dos projetos Evolvet e Plan3D.

## Finalidade

O aplicativo utiliza a API do Google Drive para armazenar cópias de segurança criptografadas, ajudando a proteger os arquivos e bancos de dados dos projetos contra perdas acidentais e falhas de infraestrutura.

## Funcionamento

Os backups são criptografados antes de serem enviados ao Google Drive. O acesso é autorizado pelo proprietário da conta Google e utilizado exclusivamente para operações de armazenamento e recuperação das cópias de segurança.

Este aplicativo não oferece um serviço público, não permite cadastro de usuários externos e não comercializa dados.
